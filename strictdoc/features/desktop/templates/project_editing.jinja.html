{# What the pages of a project of the desktop application do about the files that change while the user types. base.jinja.html includes it, through the indicator, for the servers of the application only. An editor or a form that is open takes a lease (a short one, that the page renews every few seconds). While a lease lives, the application does not change the files of the working copy: the update waits for the end of the typing. A page that is asked to reload while an editor is open tells it and reloads when the editor is closed. A save that comes from a form that was opened on files that changed since is refused by the server, and the text stays on the screen. What counts as an editor, in this order: - a form with a field to fill in that is shown, or that was changed (its value is not the one that the page gave it): the node, the creation of a node, the configuration of the document, the grammar, a folder, the title of the project, an import, the cells of the table that are edited, and the editors of Markdown that are in these forms. A form that is always in the page and whose fields are hidden (the edit form of a comment, in a closed "details") is not an editor until it is opened or changed. A list of values (a "select") counts when it was changed or has the focus: a list that the page shows at rest is not an editor; - the form of the comments, once something is typed in it; - the proposals of the assistant that wait to be applied (the button "apply" of the bar, the form of the proposals of the page of a draft); - a field that has the focus and is not in a form (the cells of the table with a list of values, the fields of the page of an item). The server refuses a save that comes from a form opened on older files. The revision that the page sends is the one of the oldest editor of the typing, and the page keeps it after the editor leaves the page: a field that saves when it loses the focus (the cells with a list of values) has no editor any more when its request starts, and a bar or a form that is removed before its request keeps the revision for a few seconds. The saves that carry typed text all go through "fetch" (Turbo, and the scripts of the table), which this script completes. The forms that the browser submits by itself have no text typed in them: the git and suspect pages (buttons), and the page of the reviewers, which does not use the base template and has no code of the application. Not counted: the search, the differences, the export of a Word document, the question to the assistant, the synchronization and the merge window, text zone included (they do not change the files by themselves, and the merge must go on). #}
